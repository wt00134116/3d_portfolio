# ปรับส่วนแสดงผลงาน (Works) เป็น feature rows

วันที่: 2026-09-16

## ปัญหา

ส่วน Works ปัจจุบันเป็น grid การ์ด 3 คอลัมน์ แต่มีผลงานจริงแค่ 2 ชิ้น ทำให้เหลือที่ว่างครึ่งจอและดูเหมือนยังทำไม่เสร็จ
การ์ดแต่ละใบยังบอกแค่ "ระบบนี้ทำอะไร" ไม่ได้บอกบทบาทของเจ้าของพอร์ตและผลลัพธ์ที่เกิดขึ้น

## เป้าหมาย

- รองรับผลงาน 4-6 ชิ้น และรูป screenshot หลายรูปต่อโปรเจค
- เน้นผลลัพธ์ของงาน ไม่ใช่แค่คำอธิบายระบบ
- ยังคงหลักการ "เพิ่มโปรเจคใหม่ = แก้ไฟล์เดียว" ที่ทำไว้ก่อนหน้า

## การออกแบบ

### Layout

แต่ละโปรเจคเป็นแถวเต็มความกว้าง แบ่ง 2 คอลัมน์ (รูป / ข้อความ) และสลับข้างตามลำดับ
แถวเลขคู่รูปอยู่ซ้าย แถวเลขคี่รูปอยู่ขวา บนจอเล็กกว่า `lg` ยุบเป็นแนวตั้งโดยรูปอยู่บนเสมอ

### ฝั่งรูป

- รูปหลักอยู่ในกรอบเบราว์เซอร์จำลอง (แถบบนมีวงกลม 3 วง) เพื่อให้ screenshot ดูเป็นเว็บจริง
- ถ้ามีมากกว่า 1 รูป แสดงแถบรูปเล็กด้านล่าง คลิกเพื่อสลับรูปหลัก รูปที่เลือกอยู่มีขอบไฮไลต์
- ถ้ามีรูปเดียว ไม่แสดงแถบรูปเล็ก

### ฝั่งข้อความ

เรียงจากบนลงล่าง โดยทุกส่วนยกเว้นชื่อและคำอธิบายจะหายไปเงียบๆ ถ้าไม่มีข้อมูล:

1. บรรทัดบริบท: `category · year`
2. ชื่อโปรเจค
3. คำอธิบายสั้น
4. รายการผลลัพธ์ (`highlights`) แต่ละข้อมีไอคอนติ๊กนำหน้า
5. ชิปเทคโนโลยี ใช้ไอคอนจริงจาก `src/assets/tech` ถ้าจับคู่ชื่อได้ ถ้าไม่ได้แสดงเป็นข้อความอย่างเดียว
6. ปุ่มลิงก์ source code แสดงเฉพาะเมื่อมี `source_code_link`

### Animation

ใช้ `fadeIn` จาก `utils/motion.js` ที่มีอยู่แล้ว ให้แถวเลื่อนเข้าจากฝั่งเดียวกับรูปเพื่อให้การสลับข้างรู้สึกตั้งใจ

## โครงสร้างข้อมูล

`src/constants/projects.js` ยังเป็นไฟล์เดียวที่ต้องแก้เวลาเพิ่มโปรเจค

```js
{
  name: "Purchase Web",          // จำเป็น
  description: "...",            // จำเป็น
  images: ["a.jpg", "b.jpg"],    // ชื่อไฟล์ในโฟลเดอร์ src/assets/projects/
  category: "ระบบจัดซื้อ",        // ไม่บังคับ
  year: "2023",                  // ไม่บังคับ
  highlights: ["..."],           // ไม่บังคับ แต่เป็นส่วนที่ทำให้พอร์ตน่าสนใจที่สุด
  tags: ["php", "sqlserver"],    // ไม่บังคับ สีใส่ให้อัตโนมัติ
  source_code_link: "https://…", // ไม่บังคับ
}
```

รองรับรูปแบบเดิมด้วย: `image: "x.jpg"` (รูปเดียว) และ `tags: [{ name, color }]` ยังใช้ได้

## ขอบเขตที่ไม่ทำ

- ไม่ทำ modal / lightbox ขยายรูป — ใช้แถบรูปเล็กสลับรูปในที่เดียว
- ไม่ทำ filter ตามหมวด — ยังไม่คุ้มที่จำนวนผลงาน 4-6 ชิ้น
- ไม่แต่งเนื้อหา `highlights` ขึ้นเอง เจ้าของพอร์ตเป็นคนใส่ตัวเลขและผลลัพธ์จริง

## การตรวจสอบ

- `npm run build` ผ่าน
- เปิดดูจริงบนเบราว์เซอร์: การสลับข้างของแถว, การคลิกรูปเล็กสลับรูปหลัก, การยุบเป็นแนวตั้งบนจอมือถือ, และกรณีโปรเจคที่ไม่มี `highlights` / มีรูปเดียว
